# Sruthi Shivaramakrishnan: personal site

A static site for GitHub Pages. No build step or framework.

## Files
- `index.html`: home, research and projects, experience, education, talks and awards, contact.
- `thoughts.html`: open problems. Add each question as a `problem-card` (there is a template in a comment in the file) and delete the "coming soon" card.
- `style.css`: all styling.
- `script.js`: mobile menu, nav highlighting, footer year.

## GitHub Pages setup
1. Put the files in the **root** of the `sruShiva.github.io` repository (not in a subfolder).
2. Settings, Pages, Deploy from a branch, `main`, `/ (root)`.
3. The site appears at https://srushiva.github.io/.

## Notes
- Keep Experience in reverse-chronological order when you add roles.
- The "↗" arrow is only used on real links.
- Fonts load from Google Fonts via `<link>` tags; system fonts are the fallback.
